# Noto fonts

Noto Sans Arabic, Noto Sans Hebrew, Noto Sans Thai and Noto Sans Devanagari are
copyright The Noto Project Authors and licensed under the SIL Open Font License
1.1. The original licence and copyright notice for each font are in the adjacent
NotoSans*-LICENSE.txt files.

The font files are static Bold instances (weight 700, width 100) made with fontTools varLib.instancer from
the variable fonts in the Google Fonts repository, so captions use one weight whatever the renderer's default
instance; nothing else was changed:

- Noto Sans Arabic: https://github.com/google/fonts/tree/main/ofl/notosansarabic
- Noto Sans Hebrew: https://github.com/google/fonts/tree/main/ofl/notosanshebrew
- Noto Sans Thai: https://github.com/google/fonts/tree/main/ofl/notosansthai
- Noto Sans Devanagari: https://github.com/google/fonts/tree/main/ofl/notosansdevanagari
